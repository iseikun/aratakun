# ブラック企業社長シミュレーター // React & Next.js Edition

> **React の宣言的 UI / Hooks と Next.js の Server Actions をフル活用した、ワンマンブラック企業経営シミュレーションゲーム**

---

## 🏢 ゲームの概要

あなたは IT ベンチャーの代表取締役社長。  
社員（フロントエンド、バックエンド、フルスタック、無給インターン）を限界まで酷使し、炎上デスマーチ案件を次々に納品して、**会社資産 1,000 万円での東証グロース上場（IPO）** を目指します。

しかし、過剰な残業や激詰めを続けると **「労働基準監督署の警戒度」** が上昇！  
抜き打ちの家宅捜索で罰金を科される前に、**Next.js Server Actions でタイムカード DB を直接改ざん** して証拠隠滅しながら、億万長者を目指してください。

---

## ⚡ React & Next.js の特徴を活かしたゲームシステム

### 1. 社長が発動する「React Hooks 経営コマンド」
- `useState: みなし残業45時間固定`  
  基本給に残業代を包含！社員の給与支払いを State として固定し、人件費を圧縮。
- `useEffect: 業務後強制飲み会`  
  定時退社後に副作用発動！社長の武勇伝を語って忠誠心を高める（社員の体力激減）。
- `useMemo: 経費削減キャッシュ (エアコン停止)`  
  冷暖房をカットして即時現金を捻出。
- `useReducer: 恐怖の30分刻み日報`  
  厳格な Reducer ルールでサボりを根絶し、生産性を強制ブースト。
- `Suspense: 徹夜デスマ・ストリーミング`  
  納期直前の案件進捗をストリーミングのように一気に消化！
- `createPortal: 「学べる環境」無給インターン召喚`  
  社外から夢見る若者をワープ召喚。月給ほぼゼロの即戦力として補充。

### 2. Next.js Server Actions による「労基署対策・裏工作」
- `executeServerActionFalsify` (`'use server'`)  
  ブラウザの DevTools や履歴に残らないサーバーサイドで実行される裏工作。深夜残業記録を「全員18:00定時退社」として DB 書き換えを行い、労基署の警戒度を劇的に減少させます。
- `auditLaborInspection` (`'use server'`)  
  労基署の抜き打ち査察判定をサーバー側でセキュアに計算。チート不可能な確率判定を実施。
- `deliverProjectServer` (`'use server'`)  
  完成した炎上案件の納品とクライアントからの売上着金処理をサーバーサイドでセキュアに決済。

### 3. 社員コンポーネントとエラー境界（React Component Architecture）
- 社員一人一人が独立した体力（HP）と精神力（Mental）の State を保持。
- メンタルが 0 になると **退職代行モームリから委任状が届き会社から離脱**！
- 体力が 0 になると **過労で救急搬送** され翌日の稼働がストップ！

### 4. ゼロアセット Web Audio エンジン
- 外部音声ファイルを一切使わず、ブラウザの Web Audio API でキーボード猛打音、エナジードリンク開封音（カシュッ！）、労基署サイレン音、売上着金音（チャリン！）、社長の怒号などをリアルタイム合成。

## 🚀 起動方法

### 1. パッケージのインストール
```bash
npm install
```

### 2. 開発サーバーの起動
```bash
npm run dev
```

ブラウザで [http://localhost:3000](http://localhost:3000) を開いてゲームをプレイしてください！
